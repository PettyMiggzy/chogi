How to upload to telegram

1

Download all 15 PNGs above (tap each ⬇ PNG button). Save them to your phone's Photos / Files.

tip: save them in order — 01_gm, 02_wagmi, etc — so the pack stays organized
2

Open Telegram and message @Stickers — that's the official Telegram bot for sticker packs.

tap the search icon, type "stickers", select the bot with the blue checkmark
3

Send /newpack to the bot. It'll ask for a name — type Chogi · Experiment 7777 or whatever you want.

4

Send each sticker PNG as a file (not photo), one by one. Tap the 📎 attach icon → "File" → pick the PNG.

after each one, the bot asks for an emoji. suggested emojis below.
5

After all 15, send /publish. The bot asks for a sticker pack icon (use 15_heart.png) and a short URL name like chogi7777.

6

Done. The bot gives you a t.me/addstickers/chogi7777 link. Share it everywhere — pin in the TG, drop in X bio, post on chog.xyz Discord.
